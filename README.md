# Spendly｜家計簿

GitHub Pagesで公開する静的な家計簿アプリです。

## データの持ち方

- **実データはこのリポジトリには置きません。**
- **記録の流れ**：アプリで保存すると、まず端末（localStorage）に保存され、次にGoogleスプレッドシート「Spendly家計簿」へ自動同期されます（受け口はGoogle Apps Script）。電波がないときは未送信分が端末に残り、次に開いたとき・オンライン復帰時に送り直されます。
- **シートが共有の正本**：シート側で追加・変更された記録（ヴェーダが明細・レシートから特定した「ヴェーダ記録」など）も、同期時にアプリへ取り込まれます。
- **同期設定**：受け口URLと合言葉（TOKEN）はアプリの「同期設定」から入力し、端末にのみ保存されます（このリポジトリには含まれません）。
- **バックアップ**：アプリ内の「自分のデータを書き出す」でJSONに保存できます。「読み込む」でのJSON取り込みも可能です（重複は自動スキップ）。
- `data.json` は互換のために残している空データです（アプリはもう読みません）。

## 公開方法（GitHub Pages）

1. リポジトリの **Settings → Pages** を開く
2. Build and deployment の Source で **Deploy from a branch** を選ぶ
3. Branch で **main / (root)** を選んで Save
4. 数分後に `https://lostboy777-112.github.io/Spendly-app/` で公開されます

## ファイル

- `index.html` — アプリ本体（HTML/CSS/JSを1ファイルに収録、外部依存なし）
- `data.json` — ヴェーダ記録のデータ

# Spendly｜家計簿

GitHub Pagesで公開する、iPhone向けの家計簿アプリです。ビルドはありません。

公開ページ: https://lostboy777-112.github.io/Spendly-app/

**正本はGoogleスプレッドシート「Spendly家計簿」です。** 家計簿の記入は主にAI（ヴェーダ／ハロ）がシートへ直接行い、アプリはその内容を表示します。アプリで追加・編集した記録も、連携を通じてシートへ送られ、シートが正となります。連携の方式（接続方法・Apps Scriptの構成・アプリの接続設定）は別リポジトリ [budget-app](https://github.com/lostboy777-112/budget-app) と同じにしてあります。

## 機能

- 月ごとに収入・支出・収支を表示します。‹ 前月 / 次月 › で月を移動できます。
- カテゴリ別の支出合計をバーで表示します。
- 記録は日付・種別（支出／収入）・金額・カテゴリ・内容・メモで構成されます。一覧の行を開くと編集・削除ができます。
- 記録者バッジ: AIが記録したものは「ヴェーダ記録」、自分で入れたものは「自分」。シートへ未送信のものには「未送信」バッジが付きます。
- 連携を設定すると、アプリを開くたび・オンライン復帰時・画面の再表示時に、未送信分を送ってからシート全件を読み直します。

## データの保存

| キー | 内容 |
| --- | --- |
| `spendly-v1` | シートの内容の端末内キャッシュ（表示用）。 |
| `spendly-sync-v1` | 送信先URL、合言葉、未送信のキュー、最終送信・最終取得時刻、最後のエラー。 |

Safariのサイトデータや履歴を消すと、これらのキーも消えます（正本はシートなので、再取得すれば復元されます）。

## スプレッドシート連携

接続方法は budget-app と同じです。

- 変更のたびに、端末内のキューへイベントを積み、送れるときにまとめて POST します。`{ok:true}` が返ったイベントだけをキューから外します。それ以外（オフライン、合言葉の不一致、通信失敗）は残し、あとで送り直します。送り直すタイミングは、アプリを開いたとき、オンラインに戻ったとき、画面が再表示されたとき、次の変更のあと、そして URL と合言葉を保存したときです。
- 送信のあと、アプリは GET でシートの全件を取得し、シートの内容を正として画面を組み直します。未送信の変更がある記録だけは、端末側の内容を優先します。
- 設定ページ（右上の「⚙ 設定」から開く）の「スプレッドシート連携」には、最終送信・最終取得（日本時間）、保留件数、最後のエラーが出ます。「接続テスト」は `{type:"ping"}` を送り、`{ok:true, pong:true}` なら成功です。「シートから読み直す」は全件の再取得、「全データを送り直す」は、いま表示されている全記録を送り直します。
- 送信先に使えるのは `https://script.google.com/macros/s/…/exec` だけです。それ以外は保存できても送らず、設定に理由を出します。1回の送信は500件までです。

### シート「記録」（IDごとに1行）

| ID | 日付 | 月 | 種別 | カテゴリ | 金額 | 内容 | メモ | 記録者 | 更新日時 | 削除 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

- 種別は「支出」／「収入」、記録者は「自分」／「ヴェーダ」で書きます。
- アプリで削除しても行は消えません。削除列が TRUE になり、更新日時が更新されます。
- 届いた `更新日時`（updatedAt）が、行にある更新日時より古いときは、そのイベントを無視します。
- シート側は、文字の列を文字列として書き、`=` `+` `-` `@` やタブ、改行で始まる文字には先頭に `'` を付けます。金額は数値だけです。合言葉が違う、IDや日付の形が違う、カテゴリ・内容・メモが200文字を超えるイベントは飛ばし、応答の `skipped` に件数を入れます。

### AI（ヴェーダ／ハロ）がシートへ直接書くとき

Apps Scriptを経由せずシートへ直接行を追加する場合も、上の形式に合わせてください。

- IDは英数字と `_` `-` の64文字以内で一意にします。
- 日付は `YYYY-MM-DD`、月は `YYYY-MM`、更新日時はISO形式（例 `2026-11-13T08:55:00.000Z`）で書きます。
- アプリは次に開いたとき、その行を取り込んで表示します。

### 設定手順

手順の詳細は [gas/SETUP.md](gas/SETUP.md) です。概要だけ書くと、スプレッドシートの拡張機能から Apps Script を開き、`gas/Code.gs` を貼り、スクリプト プロパティ `SYNC_TOKEN` に合言葉を入れ、ウェブアプリとしてデプロイします。実行するユーザーは「自分」、アクセスできるユーザーは「全員」です。表示された `/exec` で終わる URL と、同じ合言葉を、アプリの設定ページ（右上の「⚙ 設定」）の「スプレッドシート連携」に入力します。合言葉の入力欄は非表示です。

`gas/Code.gs` を直したときは、スプレッドシートの Apps Script に新しい中身を貼り、**デプロイを管理 → 編集 → バージョン「新バージョン」** でデプロイし直してください。URL はそのままです。新しいデプロイを作ると URL が変わります。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の骨組みとスタイル。スクリプトは外に出しています。 |
| `app.js` | 記録、画面の操作、シートからの取得と画面への反映。 |
| `sync.js` | 送信キューと POST、シート全件の GET。 |
| `gas/Code.gs` | スプレッドシートに結び付いた Apps Script。 |
| `gas/SETUP.md` | 連携の設定手順。 |
| `.nojekyll` | GitHub Pages が Jekyll でファイルを加工しないようにする空ファイル。 |
| `data.json` | 旧バージョンの名残（空）。現在のアプリは読みません。 |

## セキュリティ

このリポジトリに、送信先 URL、合言葉、支出の中身は置きません。合言葉は、Apps Script のスクリプト プロパティ `SYNC_TOKEN` と、入力した端末の `spendly-sync-v1` だけにあります。

ウェブアプリのアクセスは「全員」です。URL を知っていれば開けます。記録の書き込みと全件の読み取りは、合言葉が一致したリクエストだけです。URL と合言葉は、リポジトリやチャットに書かないでください。

「書き出す」でできる JSON は支出データです。コミットしないでください。`.gitignore` は `spendly-data.json` と `*.export.json` を無視します。

## 毎日の使い方

1. アプリを開くと、シートの最新内容が表示されます（連携設定時）。
2. 自分で記録するときは「＋ 記録を追加」から入力します。保存するとキューに積まれ、つながっているときにシートへ送られます。
3. 行を開くと編集・削除ができます。

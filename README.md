# Spendly｜家計簿

GitHub Pagesで公開する静的な家計簿アプリです。

## データの持ち方

- **実データはこのリポジトリには置きません。** アプリのデータはすべて利用者のブラウザ（localStorage）にのみ保存され、サーバには送信されません。
- **自分の入力**：アプリ内で追加・編集・削除できます。機種変更などに備えて、アプリ内の「自分のデータを書き出す」でバックアップできます。
- **ヴェーダ記録**：カード明細・レシート・本人の確認から特定できた支出を、ヴェーダがJSONファイルとして本人に渡します。アプリの「読み込む」から取り込むと、端末内に「ヴェーダ記録」バッジ付きで表示されます（重複は自動スキップ）。
- `data.json` は互換のために残している空データです。

## 公開方法（GitHub Pages）

1. リポジトリの **Settings → Pages** を開く
2. Build and deployment の Source で **Deploy from a branch** を選ぶ
3. Branch で **main / (root)** を選んで Save
4. 数分後に `https://lostboy777-112.github.io/Spendly-app/` で公開されます

## ファイル

- `index.html` — アプリ本体（HTML/CSS/JSを1ファイルに収録、外部依存なし）
- `data.json` — ヴェーダ記録のデータ

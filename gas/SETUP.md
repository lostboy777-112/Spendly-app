# スプレッドシート連携の設定

家計簿アプリ（Spendly）の正本は、Googleスプレッドシート「Spendly家計簿」です。この手順で、アプリとシートをつなぎます。

合言葉とウェブアプリの URL は、あなただけが知っていれば十分です。GitHub のリポジトリ、メール、チャット、スクリーンショットには書かないでください。アプリに入力した値は、その端末の中だけに保存されます。

## 1. 合言葉を決める

長くて、ほかのサービスで使っていない文字列にしてください。このあと、Apps Script のスクリプト プロパティ `SYNC_TOKEN` と、アプリの「合言葉」の両方に、同じ文字列を入れます。

## 2. スプレッドシートを用意する

1. スプレッドシート「Spendly家計簿」を開きます（無ければ [Google スプレッドシート](https://sheets.google.com/) で新規作成）。
2. メニューの **拡張機能** → **Apps Script** を開きます。

スマホしかない場合は、Safari で script.google.com を開き、新しいプロジェクトを作って同じ手順を進められます。その場合、`gas/Code.gs` の `SpreadsheetApp.getActiveSpreadsheet()` を `SpreadsheetApp.openById('<シートID>')` に書き換えてください（シートに紐づいていないプロジェクトでは、こちらが必要です）。

## 3. スクリプトを貼る

1. 最初から入っている `コード.gs`（または `Code.gs`）の中身を、すべて消します。
2. このリポジトリの `gas/Code.gs` を開き、中身をすべてコピーして貼り付けます。
3. 保存します（フロッピーのアイコン、または Ctrl+S / ⌘S）。

`Code.gs` に合言葉や支出の金額を書き足さないでください。合言葉は、次のプロパティだけに入れます。

## 4. 合言葉をスクリプト プロパティに入れる

1. 左の **プロジェクトの設定**（歯車）を開きます。
2. 下の方にある **スクリプト プロパティ** で **スクリプト プロパティを追加** を押します。
3. プロパティは `SYNC_TOKEN` と入力します。大文字・小文字もこのとおりにしてください。
4. 値に、手順 1 で決めた合言葉を入れます。
5. **スクリプト プロパティを保存** を押します。

## 5. ウェブアプリとして公開する

1. 右上の **デプロイ** → **新しいデプロイ** を開きます。
2. 歯車の **種類の選択** で **ウェブアプリ** を選びます。
3. 次のように設定します。
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: 全員
4. **デプロイ** を押します。
5. Google の確認が出たら、許可します。自分のスプレッドシートを更新するための確認です。
6. 表示された **ウェブアプリの URL** をコピーします。`/exec` で終わる URL を使ってください。

`Code.gs` を直したときは、次のようにして、いまの URL のまま新しいコードを出します。

1. **デプロイ** → **デプロイを管理** を開きます。
2. 使っているウェブアプリの鉛筆（**編集**）を押します。
3. バージョンを **新バージョン** にして、**デプロイ** を押します。

**新しいデプロイ** を作ると URL が変わります。変わったときだけ、アプリの送信先 URL を差し替えてください。アプリが受け付けるのは `https://script.google.com/macros/s/…/exec` です。

## 6. アプリに URL と合言葉を入れる

1. iPhone で Spendly を開きます（GitHub Pages の URL から）。
2. 右上の **⚙ 設定** を開き、**スプレッドシート連携** に、コピーした URL と、同じ合言葉を入力します。
3. **接続テスト** を押します。「接続できました」と出れば届いています。
4. **シートから読み直す** を押すと、正本（シート）の内容がアプリに反映されます。それまでの端末内の記録もシートへ載せるときは、**全データを送り直す** を押します。

シート「記録」は、最初の送信のときに作られます。見出しの行も自動で付きます。

## 7. 届いたデータの見方

- **記録** は ID ごとに 1 行です。アプリで削除しても行は消えず、**削除** 列が TRUE になります。
- アプリは開くたびにシートの全件を読み直し、シートの内容を正として表示します（端末は表示と未送信分の置き場です）。
- 同じ記録が古い時刻で届いたときは、シート側の新しい行を上書きしません。

## うまくいかないとき

- 「合言葉が一致しません」と出る: アプリの合言葉と、`SYNC_TOKEN` の値が同じか確認します。`Code.gs` も直したときは、上の「新バージョン」でデプロイし直します。URL は変えないでください。
- 接続テストが失敗する: URL が `https://script.google.com/macros/s/…/exec` か、アクセスできるユーザーが「全員」かを確認します。別の形の URL は、アプリが送りません。
- 記録がシートに増えない: アプリはオフラインでも使えます。電波が戻ってアプリを開くと、残っている分を送り直します。連携の状態欄に、最後に送れた時刻、残っている件数、最後のエラーが出ます。
